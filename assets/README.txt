Branding assets for ChemSync.

logo.png     — sidebar header logo.
               Ideal: 600–900 px wide, transparent PNG, the wordmark version
               (logo + "CHEMIGRAN" text), since it renders across the full
               sidebar width. Light-coloured artwork reads best on the dark
               theme; a dark-on-transparent logo will disappear.

favicon.png  — optional. Browser tab icon. Square, 128x128 or 256x256, just
               the "C" mark without the wordmark. If absent, logo.png is used.

Accepted extensions: png, webp, jpg, jpeg, svg (logo) / png, ico, jpg (favicon).
Nothing else needs changing — app.py picks these up automatically and falls
back to the leaf emoji when they are missing.
